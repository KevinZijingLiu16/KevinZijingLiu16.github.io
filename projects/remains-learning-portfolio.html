Remains learning portfolio

A course reflection written for evaluation at JAMK University of Applied Sciences.

What I did

As the sole programmer and technical lead, I was responsible for translating the team's gameplay concepts into functional systems and ensuring the technical foundation of the project was stable, scalable, and accessible to all team members. Over the three-month development period, I designed and implemented 17 modular gameplay systems, structured using clean C# practices and SOLID principles. These systems included player movement, spline track logic, state machines for enemies and NPCs, camera control, interaction systems, save/load logic, UI systems, and multiple environmental mechanics.

Beyond implementation, I produced technical design documentation and flowcharts to describe system structures and interactions, which helped the team maintain a shared technical understanding. I converted key gameplay objects into reusable prefabs, enabling non-technical team members to build levels efficiently without modifying code.

I also implemented the Opening Scene, Main Menu Scene, and Tutorial Scene, integrating gameplay logic with UI and system dependencies. Additionally, I managed the team's GitHub repository, handled pull request reviews, and maintained a stable main branch, supporting collaborative development practices.

What I learned

Technical growth

This project significantly strengthened my ability to design scalable and reusable game systems. Working as the sole programmer forced me to think beyond short-term solutions and focus on long-term maintainability. I learned how to structure interconnected systems so that they function as a cohesive gameplay experience while remaining modular and extendable.

I also gained practical experience applying game design patterns and transforming abstract design ideas into concrete mechanics. Many systems developed in this project are not project-specific and now form part of my reusable personal codebase.

Leadership and collaboration

Being the only programmer taught me that technical leadership is not only about writing code but about enabling others to work effectively. Creating prefabs, documentation, and stable systems allowed non-programmers to contribute confidently. I learned that providing clear tools is often more impactful than directly doing tasks for others.

I also developed stronger communication skills by regularly discussing technical constraints with designers and artists, helping align gameplay ideas with realistic implementation scope.

Project awareness

One of my biggest realizations was the importance of early scope alignment. Some systems were fully implemented but not used in the final build, showing a gap between early technical enthusiasm and final design direction. In future projects, I would prioritize earlier design validation and milestone checks before implementing complex systems.

Group contribution

My primary contribution to the group was providing a stable and accessible technical foundation. By modularizing systems and preparing prefabs, I reduced technical barriers for teammates and improved workflow efficiency. I supported the designer by translating gameplay ideas into working mechanics and assisted the artist by integrating assets into functional gameplay contexts.

Managing version control also supported team cohesion, as it prevented technical issues from blocking others' work. At the same time, I received support from teammates through gameplay feedback, visual design direction, and testing, which helped refine system behavior.

Self-assessment and next steps

This project demonstrated my strength in system architecture and technical problem solving. I am confident in designing maintainable gameplay systems and supporting multidisciplinary teams through technical structure.

However, I identified areas for improvement. I tend to focus heavily on system completeness, which can lead to over-engineering when scope is not clearly defined. In future projects, I aim to improve feature prioritization and scope validation before implementation.

I also want to deepen my knowledge in technical art and visual integration, as the absence of a technical artist highlighted the importance of bridging the gap between code and visuals.

Career direction

Through this project, I confirmed my interest in becoming a gameplay systems programmer and technical designer, focusing on building modular gameplay architectures and tools that support both players and development teams.

To reach this goal, I plan to continue improving in advanced system architecture, performance optimization, and cross-disciplinary communication.
