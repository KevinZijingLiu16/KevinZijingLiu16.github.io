Remains

A small robot wakes up in a forest after the end of the world and explores it with a foam gun and a vacuum. I was the only programmer and the technical lead.

  • Designed and wrote 17 modular gameplay systems, from spline-locked movement to enemy and NPC state machines and save/load.
  • Turned key objects into prefabs so a level designer new to Unity could build Level 1 without touching code.
  • Ran the GitHub repository and reviewed every pull request to keep the main branch stable.
  • Unity
  • C#
  • Splines
  • Timeline
  • Input System

Paper Blast

A 2D platformer where any PDF you import becomes destructible terrain. You jump across lines of text and blast through paragraphs with rockets, lasers, a black hole and an eraser.

  • Keeps the visible page and its pixel collision mask in sync, re-uploading only the chunks a blast changed.
  • Turns text lines into one-way platforms, with an image-based fallback for scanned pages.
  • Nine assembly modules with dependency rules enforced by tests, and more than 300 edit-mode tests.
  • Unity
  • C#
  • Docnet (PDF)
  • NUnit
  • Assembly definitions

Individual project, 2025

Mannequin Escape

Collect items before time runs out while other mannequins hunt you. Knock them back with energy waves or trip them with traps.

  • Enemy AI with separate sight, hearing and hit senses that feed a patrol, chase and attack state machine.
  • Inventory, game manager and UI built on MVC so they can move into the next project unchanged.
  • Modelled, rigged and animated the character in Blender, then layered procedural animation on top in Unity.
  • Unity
  • C#
  • NavMesh
  • Blender
  • Animation Rigging

Mobile, AR and online, 2025

KL Beyblade World Cup

An online spinning-top battle for Android. Players place the arena on a real surface with AR and fight each other over the network.

  • Lobby, matchmaking and player selection on Photon PUN 2.
  • Custom Rigidbody synchronisation that predicts each remote top from its velocity and the measured network lag.
  • AR mode that places the arena on a real surface, plus touch joystick controls.
  • Unity
  • C#
  • Photon PUN 2
  • AR
  • Android
